# LOGOS 웹 프로토타입

흩어진 사실과 기록을 연결해 사건의 전체 이동 경로를 복원하는 브라우저 추리 게임입니다.

## 실행

별도의 설치나 빌드가 필요하지 않습니다.

1. `index.html`을 Chrome 또는 Edge로 엽니다.
2. 타이틀의 `게임 시작`을 누릅니다.
3. 《사라진 제24면》을 선택해 조사를 시작합니다.

인터넷 연결 없이도 핵심 플레이가 동작합니다. 진행 상황은 현재 브라우저의 `localStorage`에 자동 저장되며, 설정에서 JSON 파일로 내보내거나 다시 불러올 수 있습니다.

## 구현된 범위

- 원본 `로고스 타이틀.png` 기반 반응형 타이틀 화면
- 로고시아 서가와 작품 선택
- 사건 브리핑과 세 장소 조사
- 사실 데이터에 고정된 NPC 문답
- 기록 12개 수집·열람
- 기록 비교를 위한 타임라인
- 두 기록의 관계를 만드는 추론 보드
- `U-108 + 규정 P-4` 연결에 따른 B-4 서랍 해금
- 다섯 개 주장에 근거를 첨부하는 LOGOS 심사
- 항목별 `충족 / 부분 충족 / 근거 부족` 판정
- 완전한 사건 복원 타임라인
- 자동 저장, 저장 파일 내보내기·불러오기
- 모바일 반응형 UI, 키보드 조작, 움직임 줄이기, 큰 글자

## 사건 설계 원칙

- 모든 기록과 NPC 진술은 확정된 사실입니다.
- NPC는 등록된 사실 밖의 내용을 새로 만들지 않습니다.
- 난이도는 정보의 분산, 버전 차이, 시간 순서, 인계 이력, 규정 적용에서 발생합니다.
- 심사는 무작위 AI 판정이 아니라 재현 가능한 사건 데이터와 근거 묶음으로 처리합니다.

## 파일

- `index.html` — 진입 문서
- `styles.css` — 전체 시각 디자인과 반응형 레이아웃
- `app.js` — 사건 데이터, 상태 저장, 조사·추론·심사 로직
- `assets/logos-title.png` — 타이틀 배경
- `assets/tsukino-cover.png` — 봉인된 다음 작품 표지

## 검증

Microsoft Edge 헤드리스 모드에서 다음 전체 흐름을 자동 완주했습니다.

`새 게임 → 브리핑 → 기록 수집 → 규정 연결 → B-4 해금 → 원본 수집 → 근거 제출 → 100% 복원 승인`
